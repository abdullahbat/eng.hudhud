- راجع ملف [`CLAUDE.md`](./CLAUDE.md) لقراءة دستور وقواعد المشروع.
- راجع ملف [`PROGRESS.md`](./PROGRESS.md) لمتابعة حالة المراحل (0 إلى 8).
